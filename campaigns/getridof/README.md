# Get Rid Of funnels

A [Campaign Page Kit](https://github.com/NextCommerceCo/next-campaign-page-kit) project. The pages are static HTML,
and the [Campaign Cart SDK](https://cart-sdk.nextcommerce.com/latest/) takes the orders in the browser.

## Mouse Pouches (`/mouse-pouches/`)

**Campaigns App campaign 2362** on getridof.29next.store:

| | |
|---|---|
| Packages | **1** Rodent Repellent Pouches ($49.99), **2** Rodent Repellent Pouches – Auto-Refill ($49.99, then $34.99 a pack every 60 days), **3** Package Protection ($3.97) |
| Offers | **Buy 1 – 40% Off** (any 1+ → $29.99), **Buy 2, Get 1 Free** (3+ → $55.98), **Buy 3, Get 2 Free** (5+ → $74.95); voucher **GROMOUSE10** = Extra 10% Off |
| Shipping | method 1, free |

The run directory `next-campaigns-create-runs/getridof-pdp135/` (gitignored, mode 600 manifest) owns the campaign:
`verify`, `edit`, `diff` / `update` run from there (`.claude/skills/next-campaigns-create`).

| Page | URL | Source |
|---|---|---|
| Sales page | `/mouse-pouches/` | `index.html`, generated by `tools/funnel/getridof/build_lp.py` from `tools/funnel/getridof/lp/` (hand-written, 79 KB) |
| Checkout | `/mouse-pouches/checkout/` | `checkout.html`, generated by `tools/funnel/getridof/build_checkout.py` (subscription and one-time bundles) |
| Thank you | `/mouse-pouches/receipt/` | `receipt.html` |

The sales page's buy box sends the shopper to the checkout with the chosen bundle preselected. "Subscribe & save" is
ticked by default and optional: ticked -> `?forceBundleId=main:buy1|buy3|buy5` (packages 2 / 5 / 6), unticked ->
`main:ot1|ot3|ot5` (package 1 x 1 / 3 / 5, no Automatic Refills terms at checkout). UTM parameters are kept. Every
buy button on the page, and the sticky bar on phones, uses the current selection.

The page-builder clone this page replaced now lives on as its own funnel, `/mouse-repellent-pouches/` (see "Replica funnel" below); its builder moved to `tools/funnel/getridof/replica/`.

### Numbers

```bash
python3 -I tools/funnel/getridof/funnel_report.py --since 2026-11-13 --applovin <AppLovin campaign export>.csv
```

prints ad clicks and spend next to what the store recorded (checkout starts = carts, orders), test traffic left out.
Page views and add-to-cart counts are in AppLovin (Axon events `page_view`, `add_to_cart`, `begin_checkout`). For
session recordings and a step-by-step funnel, set `clarity_id` (Microsoft Clarity) and/or `ga4_id` in
`_data/campaigns.json`: every page then sends `gro_*` step events (sales page: `lp/lp.js`; other pages:
`assets/js/gro-funnel.js`).

### Checks (place no order)

Serve `_site/` (for example `python3 -m http.server 8765` inside `_site`). The SDK accepts `localhost`. Then run:

```bash
node tools/funnel/getridof/e2e.cjs http://localhost:8765
```

```bash
node tools/funnel/getridof/polish_checks.cjs http://localhost:8765 campaigns/getridof/runs/polish
```

```bash
node tools/funnel/getridof/mobile_audit.cjs http://localhost:8765 campaigns/getridof/runs/mobile
```

`e2e.cjs` checks the sales page → checkout handoff and live Cart API totals (43 checks). `polish_checks.cjs` checks
bundle selection, the bump and the hosted card fields (17 checks); its evidence is in `runs/polish/`.
`mobile_audit.cjs` opens all eight steps (sales page, both checkout modes, the four offer pages, the thank-you page)
at 320, 360, 390 and 430 px wide and checks for sideways scroll, anything sticking out of the screen, text under
10 px, buy / pay buttons under 40 px, broken images and script errors (192 checks). Add `--store` to run it against
the store routes, for example `node tools/funnel/getridof/mobile_audit.cjs https://getridof.shop /tmp/mobile --store`.


### Reviews on the sales page

Three review blocks, all built by `build_lp.py`: the scrolling photo strip under the hero, the tabbed customer stories
(`REVIEWS` in `build_lp.py`, carried over from the original page) and the review wall before the questions
(`wall_section()`: the four customer photos plus the full stories). Stars are green boxed stars everywhere
(`.sbx` on the sales page, `.gro-sbx` on the checkout).

To add reviews, put them in `brand/getridof/reviews.json` (photos in `brand/getridof/reviews/`) and rebuild. Add only
reviews that real Get Rid Of customers sent, and note where each came from in `source` (required, not shown).

### Checkout layout (14 Nov 2026)

Step 1 bundle cards → PayPal / Apple Pay express buttons → contact → shipping address → payment → order button →
card logos → security badges → refill terms. There is no order bump. Express buttons skip the form, so an express
order can arrive without a phone number.

## Other hosting

1. **Host `_site/`.** On Netlify, `netlify.toml` already sets the build command (`npm run build:static`), the publish
   folder (`_site`) and Node 22. Vercel and Cloudflare Pages work too, with the same command and folder.
2. **Add a domain** in the host, for example `go.getridof.shop`.
3. **Allow the domain on campaign 2362:** Campaigns App > campaign 2362 > Settings > Allowed Domains, add it as a
   Production domain. The API cannot do this. Until it is done, the SDK refuses every call from that domain, so no
   prices and no checkout.
4. Open `https://<domain>/mouse-pouches/checkout/`. The cards should show $29.99 / $55.98 / $74.95.

## Prices (15 Nov 2026): subscription vs one-time

Both campaigns (2362 and 2716) carry the same offers. The one-time discount was cut on 15 Nov 2026 so that
subscribing is clearly cheaper; subscription prices did not change.

| Packs | Subscribe (first order) | One-time | Subscriber saves |
|---|---|---|---|
| 1 | $22.49 (55% off) | $34.99 (30% off) | $12.50 |
| 3 (Buy 2, Get 1 Free) | $47.97 (68% off) | $69.99 (53% off) | $22.02 |
| 5 (Buy 3, Get 2 Free) | $64.95 (74% off) | $104.95 (58% off) | $40.00 |

- Campaign offers on the one-time package: Buy 1 at 30.00%, 3 packs at 53.33%, 5 packs at 58.01%. The store floors the
  discounted unit price to the cent, so 30.01% lands at $34.98; keep 30.00%.
- Pages: the prices are in `T` in `tools/funnel/getridof/lp/lp.js` (sales page and listicle) and in `BUNDLES` / `SAVE`
  in `shop_checkout.py` (checkout cards and the "subscribers pay less" banners). `e2e.cjs` and `listicle_check.cjs`
  compare them with the live cart, so a campaign change without a page change fails the checks.
- Campaign changes go through `next-campaigns-create` (`diff` then `update`): run directories
  `next-campaigns-create-runs/getridof-pdp135/` (2362) and `next-campaigns-create-runs/getridof-2716/` (2716).

## Offer flow (15 Nov 2026): no prices before the checkout

After the owner's reference funnel, the sales page and the listicle show the offer but no price, and every button goes
to the checkout, where the offer is chosen.

- **Sales page and listicle:** an offer card (`.ofr`, in `tools/funnel/getridof/lp/page.html`, reused by the listicle)
  with "Buy 2, Get 1 FREE" and the bonuses; no bundle picker, no subscribe tick, no dollar amounts. Buttons carry
  `data-gro-atc` and land on `?forceBundleId=main:buy3` with the tracking parameters kept.
- **Checkout Step 1** (`step1()` in `shop_checkout.py`): a Subscribe & Save / One-time switch, then two options per
  purchase type: `1x Rodent Repellent Pouches` and the `Buy 2, Get 1 FREE` deal card (default). Bundle ids are
  `buy1` / `buy3` (subscription) and `ot1` / `ot3` (one-time). The 5-pack is no longer offered up front (it is still
  the second post-purchase offer); an old `buy5` / `ot5` link lands on the 3-pack. Headline discount: up to 68%.
- **Gifts box:** "1 FREE pack" and "Placement Guide (PDF)" come with Buy 2, Get 1 FREE and show as locked while 1x is
  selected. "FREE US shipping" and "90-day guarantee" are on every order, so they are never shown as locked.
  Do not add a bonus here that the order does not actually deliver.
- **Placement guide:** `brand/getridof/guide/placement-guide.html` → `node tools/funnel/getridof/build_guide.cjs` →
  `src/mouse-pouches/assets/guide/placement-guide.pdf`. The checkout remembers the chosen bundle for the tab
  (`sessionStorage gro_bundle`), and the thank-you page shows the download to 3-pack orders. Add the same link to the
  order confirmation email in the store settings if you want it delivered by email too.

## Sales page sections (15 Nov 2026, later pass)

- **Why it works** (`#why`, now ahead of the timeline): three logic steps, then one card per oil with its job, a CSS-animated SVG (`.an1`–`.an4` in `lp/lp.css`, 8 s loops, static under reduced motion) and a result line, then the summary box. The copy describes what each scent does; it makes no "works for every mouse" claim, and the guarantee line carries the promise.
- **Household**: two cards (Babies & kids, Pets).
- **Pack guide**: four cards (1, 2–3, 4–6, 8+ packs) with the recommendation band and a button to the checkout. `pack-8.webp` is the fourth illustration.
- **Poison-Free Formula seal** (`.pf`, inline SVG): the brand's own promise about the ingredients. It is not a third-party certificate; a real one (lab report, certifying body) can replace it when the owner has the document.
- **Timeline**: two short lines per stage. Repeated lines elsewhere were trimmed; no section was removed.
- `e2e.cjs` checks these (47 checks).

## Replica funnel: /mouse-repellent-pouches/ (campaign 2721)

A third funnel for the same product: the brand's proven product page (offline export in `exports/sofyre/offline/`),
rebuilt as Get Rid Of section for section, then the same checkout, offers and thank-you pages.

- **Campaign:** Campaigns App campaign 2721, "Get Rid Of - Rodent Repellent Pouches PDP", a clone of 2362 made with
  `next-campaigns-create` (same package, shipping and offer ids and prices, its own API key). Run directory:
  `next-campaigns-create-runs/getridof/clone-2362-pdp/` (gitignored). A price change on 2362 does not reach it.
- **Source:** the live page as captured on 15 Nov 2026 (`exports/sofyre/live-desktop/`, made with
  `exports/sofyre/tools/full.js`); it matches the HTML file the owner supplied the same day. The owner's instruction:
  an exact copy, nothing added or changed except the 90-day guarantee (plus this brand, its prices and its photos).
- **Bundle box:** the source's "offer ladder" version (12 / 36 / 60 Pouches, % OFF pill, Save $, price per pouch,
  High Demand line, BEST SELLER / LOWEST PRICE EVER badges), which the source store shows part of its visitors. Its
  markup and stylesheet are in `exports/sofyre/live-bundle-box/`. Numbers come from `replica/prices.json`: with
  Automatic Refills $22.49 / $47.97 / $64.95, one-time $34.99 / $69.99 / $104.95, compare-at $49.99 a pack;
  `build_replica.py` refuses to build if they differ from what `shop_checkout.py` charges. The refill terms are shown
  on the checkout, not on this page (the source has none there).
- **Checkout:** the standard one plus the 5-pack option (`shop_checkout.with_five_pack`), for this funnel only.
- **What differs from the source:** brand name and logo; product photos (Get Rid Of packaging); prices; 90 days
  instead of 30; "Cost per day" follows the price ($0.25); the footer (below). Nothing else: the source's colours,
  header button, press band, payment icons and copy are as they are (including its "perimetereter" typo and
  "8% concentration" line).
- **Footer** (`replica/footer.html`, styles `.gro-footer` in `replica/pdp.css`): the owner asked for a fuller one than
  the source's six links. Logo, 90-day badge, support email and hours; Shop (pouches, Mice, Groundhogs, Product
  safety, Blog), Help (Contact, FAQ anchor `#gro-faq`, Manage refills, Shipping, Refunds) and Legal (Terms, Privacy,
  Auto-refill terms, Cookie policy, Your privacy choices, Accessibility); the six payment marks this checkout takes;
  disclaimer. Only pages that exist on getridof.shop are linked (`replica_mobile_check.cjs` requests each one).
  The checkout, offer and thank-you pages of all three funnels also link Shipping, Auto-refill terms and Contact
  (`_includes/checkout-footer-links.html`, `_includes/footer.html`, `receipt.html`).
- **What could not be copied** (it only works on the source store): the Shop Pay button, cart, search, newsletter
  form, social links, the discount pop-up, and the menu's links to that store's other products.
- **Rebuilt behaviour** (the capture has no scripts; `replica/pdp.js`): bundle selection and the refills toggle,
  gallery with miniatures and swipe, both tab groups, accordions, moving photo strips and press band, review cards
  that scroll sideways on phones, countdown, menu.
- **Images:** all from `src/mouse-pouches/assets/pdp` (Get Rid Of packaging). `replica/debrand_images.py` is the
  one-off pass that removed the old brand name from the images the lean sales page never used.
- **Speed:** the first gallery photo is embedded in the HTML, photos 2-7 load after the page, the open state of the
  bundle box is written into the HTML (no script needed for the first paint), the pixel loads after the page, and
  `replica/purge_css.mjs` reduces 16 stylesheets and ~200 style blocks to one file with the rules in use
  (`GRO_NO_PURGE=1` builds without it, to compare). On a throttled phone the page paints in about 1.25 s on the
  store; layout shift 0.003.
- Never edit `src/mouse-repellent-pouches` by hand: it is regenerated and gitignored.

## 9-reason listicle funnel: /mice-9-reasons/ (campaign 2796)

A fourth funnel for the same product: listicle → checkout → home-plan quiz offer → smaller offer → thank-you.

| Page | Store route |
|---|---|
| "9 Reasons These Pouches Work When Everything Else Didn't" | `/mice-9-reasons/` |
| checkout | `/mice-9-reasons-checkout/` |
| home-plan offer (quiz) | `/mice-9-reasons-home-plan/` |
| smaller offer (after a no) | `/mice-9-reasons-last-offer/` |
| thank-you | `/mice-9-reasons-thank-you/` |

- **Campaign:** Campaigns App campaign 2796, "Get Rid Of - 9 Reasons Listicle", a clone of 2362 made with
  next-campaigns-create on 16 Nov 2026 (same packages, prices, shipping and vouchers; verified). Its public key is in
  `tools/funnel/getridof/nine/campaign.json`; the run manifest is in `next-campaigns-create-runs/` (gitignored).
- **Research:** `brand/getridof/research/amazon-review-analysis.md` (320 Amazon reviews of other brands' repellents,
  pulled with Apify on 16 Nov 2026 and tagged one by one) and `persona-and-strategy.md` (buyer persona, root problem,
  root solution, the persuasion plan and the sources).
- **Page:** `tools/funnel/getridof/nine/page.html` + `n9.css`, built by `build_nine.py` on top of the sales page's
  styles, script, top bar, offer card, animation and footer. Nine reasons; each one ends in a "Why it works" box.
  The root problem and root solution are stated right after the intro, and reason 2 carries the sales page's three
  logic steps and its card per ingredient (peppermint, cinnamon, cedarwood, castor: the job, what it does, the
  result, an animation), taken from `lp/page.html` at build time so the two pages cannot drift apart.
- **Content rules:** Amazon quotes are word for word, from other brands' listings, and the page says so. Customer
  quotes and photos are the brand's own. The "What the research says" section links each fact to its source
  (Penn State and NC State Extension, CDC, EPA, FTC, Scientific American) and says they do not endorse the brand.
  An expert appears only when `brand/getridof/expert.json` is approved and complete: a real person, in their own
  words. The page says what the product does not do (it will not evict a nest; not for groundhogs or open yards).
- **Checkout:** the standard one, with two changes for this funnel (`checkout()` in `build_nine.py`,
  `nine/checkout.css`): first and last name on one row, and the short address form of the reference checkout (only
  the address line shows until it is typed; then city, state, ZIP and phone appear). Because Subscribe & Save is
  the default, its refill size, schedule and price are also stated in the box where it is chosen (the same figures
  as the Automatic Refills terms under the button; the build stops if those terms change).
- **Offers** (`offers()` in `build_nine.py`): both pages sell package 1 (the one-time pack) with the campaign's own
  vouchers, as tier cards the SDK prices. Nothing is typed in: 1, 2 or 3 more packs use `GROU1PK30Q`, 5 packs use
  `GROU2FIVE48Q`; the smaller offer is 1 pack (`GROU1PK30Q`) or 5 packs at the lower `GROD2FIVE38Q`.
  The quiz (`nine/quiz.html`, `nine/quiz.js`) asks the home type and what else to protect, works out the plan from
  the brand's guide (one pack per zone: apartment 2, one-story 2, two-story 4, large 5, plus one for a garage/shed
  and one for a vehicle, which gives the guide's own examples: one-story + garage = 3 packs, two-story + garage = 5), subtracts the packs just ordered (`sessionStorage.gro_bundle`) and selects that card. It
  only clicks the SDK's own card; the SDK owns prices and the accept button.
- **Images:** the new photos (`brand/getridof/sections/gro-n9-*.webp`, `gro-home-*.webp`) were generated with
  Kie (Nano Banana 2); the ones that show the bag used the clean pack photo as the reference. They show the product
  in use and four home types. The generator cannot spell the bag's small print, so the hero's micro-text is softened
  and photos with an unreadable label are not used. None shows a
  person presented as an expert or a customer, and none is a before/after.
- Never edit `src/mice-9-reasons` by hand: it is regenerated and gitignored.
