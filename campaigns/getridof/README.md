# Get Rid Of funnels

A [Campaign Page Kit](https://github.com/NextCommerceCo/next-campaign-page-kit) project. The pages are static HTML,
and the [Campaign Cart SDK](https://cart-sdk.nextcommerce.com/latest/) takes the orders in the browser.

## Mouse Pouches (`/mouse-pouches/`)

**Campaigns App campaign 2362** on getridof.29next.store:

| | |
|---|---|
| Packages | **1** Rodent Repellent Pouches ($49.99), **2** Rodent Repellent Pouches – Auto-Refill ($49.99, then $34.99 a pack every 60 days), **3** Package Protection ($3.97) |
| Offers | **Buy 1 – 40% Off** (any 1+ → $29.99), **Buy 2, Get 1 Free** (3+ → $55.98), **Buy 3, Get 2 Free** (5+ → $74.95); voucher **GROMOUSE10** = Extra 10% Off |
| Shipping | method 1, free |

The run directory `next-campaigns-create-runs/getridof-pdp135/` (gitignored, mode 600 manifest) owns the campaign:
`verify`, `edit`, `diff` / `update` run from there (`.claude/skills/next-campaigns-create`).

| Page | URL | Source |
|---|---|---|
| Sales page | `/mouse-pouches/` | `index.html`, generated by `tools/funnel/getridof/build_lp.py` from `tools/funnel/getridof/lp/` (hand-written, 79 KB) |
| Checkout | `/mouse-pouches/checkout/` | `checkout.html`, generated by `tools/funnel/getridof/build_checkout.py` (subscription and one-time bundles) |
| Thank you | `/mouse-pouches/receipt/` | `receipt.html` |

The sales page's buy box sends the shopper to the checkout with the chosen bundle preselected. "Subscribe & save" is
ticked by default and optional: ticked -> `?forceBundleId=main:buy1|buy3|buy5` (packages 2 / 5 / 6), unticked ->
`main:ot1|ot3|ot5` (package 1 x 1 / 3 / 5, no Automatic Refills terms at checkout). UTM parameters are kept. Every
buy button on the page, and the sticky bar on phones, uses the current selection.

The previous sales page (a page-builder clone, 2.3 MB of HTML) is still buildable with `build_pdp.mjs` for rollback.

### Numbers

```bash
python3 -I tools/funnel/getridof/funnel_report.py --since 2026-11-13 --applovin <AppLovin campaign export>.csv
```

prints ad clicks and spend next to what the store recorded (checkout starts = carts, orders), test traffic left out.
Page views and add-to-cart counts are in AppLovin (Axon events `page_view`, `add_to_cart`, `begin_checkout`). For
session recordings and a step-by-step funnel, set `clarity_id` (Microsoft Clarity) and/or `ga4_id` in
`_data/campaigns.json`: every page then sends `gro_*` step events (sales page: `lp/lp.js`; other pages:
`assets/js/gro-funnel.js`).

### Rebuild after a change

```bash
python3 tools/funnel/getridof/build_lp.py
```

```bash
python3 tools/funnel/getridof/build_checkout.py
```

```bash
cd campaigns/getridof && npm ci && npx campaign-build
```

Edit the generators and `tools/funnel/getridof/lp/` (page.html, lp.css, lp.js), not the generated pages.

### Checks (place no order)

Serve `_site/` (for example `python3 -m http.server 8765` inside `_site`). The SDK accepts `localhost`. Then run:

```bash
node tools/funnel/getridof/e2e.cjs http://localhost:8765
```

```bash
node tools/funnel/getridof/polish_checks.cjs http://localhost:8765 campaigns/getridof/runs/polish
```

`e2e.cjs` checks the PDP → checkout handoff and live Cart API totals (24 checks). `polish_checks.cjs` checks card
selection, the bump, the hosted card fields, the express area and the exit coupon (20 checks). The evidence is in
`runs/polish/`.

## Other hosting

1. **Host `_site/`.** On Netlify, `netlify.toml` already sets the build command (`npm run build:static`), the publish
   folder (`_site`) and Node 22. Vercel and Cloudflare Pages work too, with the same command and folder.
2. **Add a domain** in the host, for example `go.getridof.shop`.
3. **Allow the domain on campaign 2362:** Campaigns App > campaign 2362 > Settings > Allowed Domains, add it as a
   Production domain. The API cannot do this. Until it is done, the SDK refuses every call from that domain, so no
   prices and no checkout.
4. Open `https://<domain>/mouse-pouches/checkout/`. The cards should show $29.99 / $55.98 / $74.95.
